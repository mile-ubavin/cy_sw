## Key Concepts Covered

### 1. Fixture Architecture & Composition
- DRY principle: define once, reuse everywhere
- Composable fixtures: build complex from simple
- cy.session() for login caching — avoids re-login on every test
- Automatic teardown handled by fixtures

### 2. Network-First Patterns
- Set up cy.intercept() BEFORE triggering the action
- Prevents race conditions (intercept after click = too late)
- Use real API for happy path E2E
- Use mocks for error handling, offline, timeout scenarios
- Project note: intercept in Create_EBox_User_Manually.js (line ~42) is already correct network-first pattern

### 3. Data Factories
- Factory functions replace hard-coded test data
- Use Date.now() in username/email for uniqueness
- Override pattern: createUserData({ role: 'admin' })
- Supports parallel test execution without conflicts

### 4. Step-File Architecture
- Micro-file design: each step is self-contained
- Just-in-time loading: only current step in memory
- Sequential enforcement, state tracking between steps
- This TEA Academy workflow itself uses this pattern
